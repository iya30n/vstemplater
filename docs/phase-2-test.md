# چک‌لیست تست فاز ۲

فایل `vstemplater-0.2.0.vsix` را با `Extensions: Install from VSIX...` نصب کن و `Developer: Reload Window` را اجرا کن. تست‌های ایمپورت را در پروژه آزمایشی انجام بده.

1. در Explorer بخش **Templates** را باز کن. گروه‌های نسخه قبلی باید موجود باشند. هر گروه را باز کن؛ فایل‌ها باید همراه مسیر والدهای ذخیره‌شده نشان داده شوند.
2. از Explorer یک فایل/پوشه جدید به تمپلیت اضافه کن؛ فهرست بدون ری‌لود پنجره باید به‌روز شود. دکمه **Refresh Templates** هم باید کار کند.
3. روی فایل تمپلیت کلیک کن یا **Edit Template File** را بزن. محتوا را تغییر بده و Save کن. دوباره بازش کن و ایمپورتش کن؛ نسخه ویرایش‌شده باید دیده شود و فایل اصلی پروژه نباید تغییر کرده باشد.
4. روی یک فایل در پنل **Import into Project** را بزن. با **Choose a new path** فقط همان فایل باید در مقصد کپی شود، بدون والدهای قدیمی یا فایل‌های دیگر گروه.
5. روی یک پوشه، ایمپورت با مسیر اصلی و سپس مقصد جدید را امتحان کن. حالت اول باید مسیر والدها را حفظ کند؛ حالت دوم باید همان پوشه و محتویاتش را زیر مقصد جدید بسازد.
6. روی نام گروه ایمپورت کن؛ تمام محتویات گروه باید وارد شوند و پوشه‌ای به نام گروه ساخته نشود.
7. با **Rename** نام یک فایل، پوشه و گروه را تغییر بده. فرزندان پوشه و مسیر ایمپورت باید نام جدید را داشته باشند. نام تکراری یا نام نامعتبر باید خطای انگلیسی بدهد و داده قبلی حفظ شود.
8. با **Delete** حذف یک فایل را ابتدا لغو و سپس تأیید کن. حذف پوشه باید فرزندانش را هم حذف کند. حذف آخرین آیتم، گروه را خالی نگه می‌دارد؛ حذف گروه باید کل گروه را از فهرست بردارد. فایل‌های پروژه اصلی باید باقی بمانند.
9. یک فایل تمپلیت را ویرایش کن اما ذخیره نکن. تغییر نام یا حذف همان فایل، پوشه والدش یا گروهش باید تا Save یا بستن فایل ذخیره‌نشده متوقف شود.
10. پوشه پروژه را ببند؛ مشاهده، ویرایش، تغییر نام و حذف تمپلیت‌ها باید ممکن باشد. ایمپورت باید پیام **Open a project first.** بدهد.
11. VS Code را ببند و باز کن. تغییر نام‌ها، حذف‌ها و محتواهای ذخیره‌شده باید باقی مانده باشند. پیام‌های افزونه باید انگلیسی باشند.
12. در دو پنجره VS Code، یک فایل تمپلیت را باز کن. در پنجره اول محتوا را تغییر بده و Save کن. ذخیره محتوای قدیمی در پنجره دوم نباید بی‌خبر جایگزین نسخه جدید شود؛ اگر خطای تعارض دیدی، تغییراتت را کپی کن و فایل را دوباره باز کن.

تست خودکار: ۲۲ تست هسته و فرمان‌ها، بررسی نوع کد و تست جداگانه بازکردن/Save در VS Code واقعی. نتیجه تست دستی بالا، معیار پایان فاز ۲ است. GitHub در این نسخه فعال نیست.
