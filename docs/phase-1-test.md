# چک‌لیست تست فاز ۱

ابتدا فایل VSIX را با دستور `Extensions: Install from VSIX...` نصب کن، یا پروژه افزونه را باز کن و F5 بزن. تست‌ها را در یک پروژه آزمایشی انجام بده.

برای بررسی اصلاح نسخه ۰.۱.۱، بعد از نصب `Developer: Reload Window` را اجرا کن. یک فایل را به تمپلیت اضافه کن و بدون بستن پیام موفقیت، ایمپورت کن. بعد از ایمپورت هم بدون بستن پیام آن، فایل دیگری اضافه کن؛ پیام «A template operation is already running.» نباید ظاهر شود.

1. پوشه `src/components/Button` شامل یک فایل متنی، یک تصویر و یک پوشه خالی بساز. روی `Button` راست‌کلیک کن؛ هر دو گزینه افزونه باید دیده شوند.
2. با `Add to Templates` گروه `UI` بساز. فایل دیگری را به گروه موجود اضافه کن. ساخت گروه جدید با نام `UI` هم باید به همان گروه اضافه کند.
3. در یک پوشه مقصد خالی، `Import from Template` و سپس `Keep original paths` را انتخاب کن. مسیر `src/components/Button` و فایل دوم باید بازسازی شوند؛ پوشه‌ای به نام `UI` نباید ساخته شود.
4. یک گروه جدا فقط از `Button` بساز؛ با `Choose a new path` آن را وارد مقصد دیگری کن. نتیجه باید `destination/Button` باشد، بدون والدهای `src/components`.
5. روی یک فایل مقصد راست‌کلیک و ایمپورت با مسیر اصلی را امتحان کن؛ محل پایه باید پوشه والد آن فایل باشد.
6. محتوای یکی از فایل‌های مقصد را تغییر بده و دوباره ایمپورت کن. ابتدا جایگزینی را لغو کن و مطمئن شو تغییری رخ نداده؛ بار دوم آن را تأیید کن و محتوای ذخیره‌شده را بررسی کن.
7. فایل منبع را پس از ذخیره تمپلیت تغییر بده. ایمپورت همچنان باید نسخه ذخیره‌شده را برگرداند. افزودن دوباره همان فایل باید تأیید جایگزینی بخواهد.
8. VS Code را کامل ببند و باز کن؛ گروه‌ها باید همچنان در فهرست ایمپورت باشند. در پروژه دیگری هم باید به همان گروه‌ها دسترسی داشته باشی.
9. `.env` و `node_modules` را داخل پوشه منبع بگذار؛ نباید ایمپورت شوند. `.env.example` باید حفظ شود.
10. نام فارسی، فایل باینری و پوشه خالی را بررسی کن. بازکردن تصویر واردشده باید بدون خرابی باشد.
11. پروژه را ببند و از Command Palette فرمان ایمپورت را اجرا کن؛ پیام `Open a project first.` باید ظاهر شود.
12. در هر مرحله Escape بزن؛ تا پیش از تأیید نهایی، فایلی نباید نوشته شود.

پنل درختی و GitHub در این فاز وجود ندارند. نتیجه این چک‌لیست، معیار شروع فاز ۲ است.
