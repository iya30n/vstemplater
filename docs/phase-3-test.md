# چک‌لیست تست فاز ۳

نسخه `vstemplater-0.3.0.vsix` را نصب کن و `Developer: Reload Window` را بزن. تست را در پروژه آزمایشی انجام بده.

1. یک تمپلیت را روی فایل هم‌نام ایمپورت کن. ابتدا جایگزینی را لغو کن؛ محتوای مقصد باید باقی بماند. دوباره اجرا و تأیید کن؛ محتوا باید جایگزین شود.
2. فایل مقصد را در ادیتور تغییر بده و ذخیره نکن. ایمپورت روی آن باید با پیام **Save or close unsaved destination files before importing.** متوقف شود. تغییراتت را Save کن و دوباره امتحان کن.
3. پنجره تأیید جایگزینی را باز نگه دار. در یک پنجره دیگر یا ابزار بیرونی، فایل مقصد را تغییر بده و ذخیره کن. سپس Replace را بزن؛ فایل جدید نباید با تمپلیت جایگزین شود و باید پیام **The destination changed. Please retry and confirm replacements.** ببینی.
4. دو پروژه را با **Add Folder to Workspace...** باز کن. از پروژه دوم یک فایل با مسیر تودرتو به گروه جدید اضافه کن؛ مسیر باید نسبت به ریشه همان پروژه ذخیره شود.
5. فرمان ایمپورت را از Command Palette یا پنل Templates اجرا کن. پروژه مقصد را انتخاب کن؛ فایل‌ها فقط باید داخل همان پروژه نوشته شوند. اگر مقصد بیرون از پروژه انتخاب‌شده باشد، باید خطا بگیری. لغو انتخاب پروژه نباید چیزی بنویسد یا قفل عملیات را نگه دارد.
6. پوشه‌ای شامل `.env`، `.ENV.PRODUCTION`، `.env.example`، `node_modules` و `.git` ذخیره کن. فقط فایل نمونه env و فایل‌های عادی باید وارد شوند.
7. در یک گروه، دو فایل از دو پوشه/پروژه مختلف با نام‌های `A.txt` و `a.txt` در مسیر یکسان اضافه کن. افزودن مورد دوم باید با **Conflicting template paths** متوقف شود و گروه قبلی حفظ شود. همین رفتار برای پوشه‌های والد `src` و `SRC` برقرار است.
8. ایمپورت پوشه خالی، فایل باینری و نام فارسی را دوباره بررسی کن. برخورد فایل با پوشه هم‌نام باید قبل از کپی خطا بدهد؛ پوشه یا فایل موجود نباید حذف شود.

تست خودکار خطای دسترسی/دیسک با خطای شبیه‌سازی‌شده انجام شده است: تعداد فایل‌های کپی‌شده گزارش می‌شود، فایل موقت پاک می‌شود و تلاش مجدد ممکن است. نیازی نیست برای تست دستی دیسک را پر کنی یا مجوز پروژه اصلی را تغییر بدهی.

کل ایمپورت گروه یک تراکنش واحد نیست؛ خطای میانه کپی می‌تواند بخشی از فایل‌ها را وارد کرده باشد. تغییرات هم‌زمان برنامه‌های دیگر با قفل سراسری فایل مهار نمی‌شوند. پشتیبانی اجرایی ویندوز و لینوکس هنوز روی دستگاه واقعی بررسی نشده است. سینک GitHub در فاز بعد می‌آید.
